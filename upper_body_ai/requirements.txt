# mediapipe is capped BELOW 1.0 deliberately.
#
# MediaPipe 1.x removed the legacy `mp.solutions` API. Every detector in this
# project (`src/pose_detector.py`, the hands graph, the drawing utils) is built
# on `mp.solutions.pose` and `mp.solutions.hands`, so an unpinned `>=0.10.0`
# quietly resolves to 1.x on a fresh install and the app dies at import with
# `module 'mediapipe' has no attribute 'solutions'`. Raise this ceiling only
# together with a port to the Tasks API.
